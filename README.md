# Mini-Projet_Crypto

Ce projet est une application de signature et de protection de fichiers utilisant des techniques cryptographiques.

## Structure du projet

- `venv/` : Environnement virtuel
- `crypto_core/` : Logique de cryptographie
- `gui/` : Interface utilisateur
- `requirements.txt` : Dépendances du projet
- `main.py` : Point d'entrée de l'application
